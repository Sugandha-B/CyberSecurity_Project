# Behavioral Monitoring Antivirus Module

## Overview

This module implements a behavior-based antivirus system that detects malicious activity at runtime.

## Features

* Process monitoring using psutil
* File activity monitoring using watchdog
* Network monitoring using scapy
* Rule-based anomaly detection
* Automatic process termination

## How to Run

```bash
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
sudo python main.py
```
